# RTL 比赛工具包

一个纯离线的 Verilog-2001 代码生成网页。打开 `index.html` 就能使用，不需要安装、联网或 AI。

## 功能

- **41 个 RTL 模板**：组合逻辑、计数与定时、寄存与移位、信号处理、状态机和 FIFO 等。
- **快速查找**：支持中文关键词搜索，以及“10 的计数器”“10 位左移寄存器”“5 个状态的状态机”等简单描述。
- **参数生成**：设置位宽、周期、状态数和复位方式，生成 Verilog-2001 代码。
- **接口适配**：粘贴模块声明或 TB 中的命名端口实例，核对端口并完成映射。
- **导出与保存**：复制或下载 `.v` 文件、生成 TB 连接骨架、保存和读取 JSON 配置。

## 使用方法

1. 下载 `index.html`，用浏览器直接打开。
2. 搜索并选择需要的 RTL 模块。
3. 调整参数，点击 **生成 Verilog-2001**。
4. 需要匹配题目接口时，使用 **粘贴 TB / 模块头** 进行端口映射。
5. 复制代码或下载 `.v` 文件，在本地仿真工具中使用。

使用 Icarus Verilog 仿真的示例：

```bash
iverilog -g2001 -s tb_top -o sim.vvp design.v tb.v
vvp sim.vvp
```

## 技术实现

原生 HTML、CSS 和 JavaScript，全部内容放在单个 `index.html` 文件中。代码生成基于预设 RTL 模板和本地规则。
