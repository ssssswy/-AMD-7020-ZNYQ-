# TraceAI 智绘逻辑分析仪

TraceAI 基于 Zynq-7020，集成八路同步逻辑采集、UART/SPI/I²C 分析、触控波形浏览，以及 PL 端 UART INT8 网络与规则触发。PS 负责数据处理和交互界面。

| 目录 | 内容 |
|---|---|
| `fpga/src/source_snapshot.zip` | 带完整相对结构的源码归档及构建入口 |
| `fpga/src/editable_reference/` | 从归档复制的 RTL、IP、PS 软件、约束和模型，便于直接浏览 |
| `fpga/build/` | 配对 BIT、XSA、ELF、MAP、硬件检查点及 PS 初始化脚本 |
| `fpga/report/` | 综合、实现、软件构建和原始验证记录 |
| `host/` | 模型文件和电脑端离线评估资料 |
| `metrics/` | 测试数据、脚本、日志和指标汇总 |
| `skill/` | FPGA 工件证据核验技能与测试 |
| `licenses/` | 现有第三方许可及待核事项 |

首次下载后，在仓库根目录执行 `python restore_large_files.py`，核验并合并源码归档及硬件检查点分卷。以恢复的归档内完整相对结构为复建依据；浏览用副本不包含全部脚本、IP 和生成输入。解压及构建条件见 [复建说明](fpga/rebuild.md)。源码归档是独立整理副本，部分历史说明与辅助脚本文字调整见 [变更记录](changes.md)。

构建工具为 Vivado/Vitis 2025.2，目标器件为 xc7z020clg400-2。已归档的实现和电脑端测试不等于实板验收；LCD 外部时序约束覆盖、连续采集与实际显示效果需要设备验证。源代码中保留的路径与工具安装相关，移植时按复建说明检查。

本地准备资料包含中文 TGF 字库和第三方组件；公开分发前需核实其来源及许可。当前未为整体作品选择许可证。
