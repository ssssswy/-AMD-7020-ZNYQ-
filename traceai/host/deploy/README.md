# 电脑环境与部署状态

现有电脑侧材料是离线仿真数据的模型和规则评估，不是实时上位机产品。它依赖 Python、NumPy、PyTorch、Cygwin GCC，以及工程内的整数参考和 C 源码；原脚本和历史配置含固定盘符路径。选定实际运行环境后，应记录操作系统、Python、NumPy、PyTorch、编译器版本并在隔离目录验证，不能把原机环境当成自动可复现环境。

当前目录未提供经验证的 Ryzen AI PC 实时推理应用、上位机与 FPGA 的在线协议实现、同步时钟方案、异常重连、传感器到执行器闭环或部署启动脚本。模型在电脑端训练和用电脑重放不代表现有运行系统已完成这些功能，也不代表已使用 ROCm 或 NPU。
