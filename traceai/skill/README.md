# FPGA 工件证据检查技能

本技能检查调用者提供的文件摘要、XSA 内嵌 BIT 配对及已有时序/DRC 摘要。入口、输入格式和边界见 [SKILL.md](fpga-build-evidence/SKILL.md)。它适用于 FPGA 构建交付审阅，不运行综合、开发板下载或应用程序。

## 使用

在工作副本根目录执行标准库行为测试：

```text
python skill/tests/test_bundle.py
```

测试使用临时样本检查正确文件、字节改动、错配、路径越界、负时序、缺失指标和返回值。测试会重写工作副本的 `skill/tests/result.json`；应先保存现有记录。工件核验命令的参数和所需清单格式在技能正文中列出，必须传入实际文件路径。

## 来源、效果与失效边界

该工作流从工程中发现的实际问题提炼：普通实现报告可能不属于最终优化工件；软件平台可能引用不同批次的 XSA；构建成功不等同于时序通过。现有 [16 项行为测试](tests/result.json) 验证检查脚本能拒绝对应的构造错误。原有历史文件 `v47_reference_audit.json` 仅用于说明工具复用，不能作为当前硬件的签核。

现有记录不能证明该技能已经在另一台电脑、全新环境或不同硬件上完成迁移。这些更强的复用结论待实际执行后补充。

没有输入的数据属于未检查。此工具不能确认约束是否充分、软件/硬件 ABI 是否匹配、现场结果是否正确、许可证是否允许公开或实板是否通过。LCD 外部输出延迟未完整约束时，非负时序摘要尤其不能单独证明外设时序满足要求。
