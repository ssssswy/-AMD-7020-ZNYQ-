# 指标与证据索引

`metrics.csv` 将实现报告、离线模型回放、近似统计和待实板数据分开。空白表示尚未实测，不表示零。每条已有结果在 `source` 列指向原始报告或逐项结果；`logs/` 保留文件原文，`scripts/` 保存对应测试入口。

## 检测结果解释

UART 数据使用封存合成数据集，主统计为 900 个异常窗、900 个正常窗。异常检出只要求目标窗出现任意报警，不要求类型正确。冻结 CNN 的检出率为 81.00%、误报率 3.56%；校验翻转正确分类为 25/120，停止位低正确分类为 51/120。

规则与 CNN 的 `AND_window` 为 PC 端窗口集合交集近似，20.78% 不是 FPGA 实际时序事件匹配后的检出率。该回放不是全新的独立数据，不衡量实时漏窗，也不是板测。实际同窗逻辑在 PL，忙时跳窗和数据覆盖还会影响整机结果。

## 复现依赖和局限

`scripts/evaluate_v49_detection_pc.py` 通过相邻的封存实验目录读取观测样本、标签、预生成特征、整数模型和主机 C 参考程序，且使用原工程相对布局与本机 GCC 路径。归档日志内可能保留本机路径，不应把这些路径当成跨机器可直接运行的命令。

单独复制已使用数据集及输入的目录和用途见 `data/README.md`。完全干净环境复算、软件编译和物理板测尚未在此目录完成。新运行不能覆盖原记录，应为新的运行生成新的结果和来源摘要。

切片规划的 130 组对照、707 个像素帧及 22 个调度帧属于主机回归，不能描述为板上 FPS 或吞吐。实板记录应填写实际接线、参数、同批 BIT/XSA/ELF、原始试次、时间和异常样本，再更新 `metrics.csv` 与设计报告。
